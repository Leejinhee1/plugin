# 브랜드 아이덴티티

제품 UI를 넘어 **브랜드가 드러나는 시각 자산**(이미지·모션·영상)의 규범과 원본을 관리합니다.
`/hds-design:brand-visual` 스킬이 이 규범을 근거로 자산을 생성/검수합니다.

## 관리 대상
- 로고 사용 규칙(여백·최소크기·금지사례)
- 브랜드 컬러 적용(제품 토큰 `color.brand.*` 와 일관)
- 모션 언어(`guidelines/motion.md` 의 이징·듀레이션을 영상에도 적용)
- 이미지·일러스트 스타일, 프로모/인트로 영상 톤

## 원칙
- 브랜드 자산의 색·모션은 제품 토큰과 **같은 언어**를 쓴다. 영상만 따로 노는 것을 금지.
- 원본(에셋 소스)과 산출물(렌더링 파일)을 구분해 원본을 이 저장소 기준으로 관리한다.

> Figma의 브랜드 파일과 동기화가 필요하면 `/hds-design:figma-bridge` 사용.
