# 로고

> 원본 벡터: `brand/assets/logo.svg`(라이트 배경용), `brand/assets/logo-dark.svg`(다크 배경용). 이 문서는 두 파일의 사용 규칙입니다.

## 1. 구성 요소

로고는 **심볼 + 워드마크**의 가로 조합(lockup)입니다. 두 요소를 임의로 분리해 다른 비율로 재조합하지 않습니다.

| 요소 | 설명 |
| :-- | :-- |
| 심볼 | 수평선 위로 떠오르는 원(하늘·해)과 구름 점 3개로 구성된 기하학 마크. "일상을 하늘에 맞추다"의 시각적 은유. |
| 워드마크 | "하늘" 한글 로고타입. `fontFamily.sans`(Pretendard 우선) 기반 볼드. |
| 색 | 심볼의 원은 `color.brand.default`(브랜드 블루) 고정. 수평선·워드마크·구름은 뉴트럴 톤(배경에 따라 전환, §4 참조). |

심볼만 단독으로 쓸 수 있는 경우는 앱 아이콘·파비콘·로딩 스피너 등 워드마크가 물리적으로 들어가지 않는 정사각형 영역뿐입니다. 그 외 모든 브랜드 표기에는 항상 워드마크를 함께 씁니다.

## 2. 최소 크기

| 매체 | 최소 크기(전체 로고 기준) |
| :-- | :-- |
| 디지털 UI(가로 로고) | 높이 20px 이상 |
| 디지털 UI(심볼만) | 24×24px 이상 |
| 인쇄물 | 높이 8mm 이상 |
| 파비콘 / 앱 아이콘 | 심볼만, 32×32px 이상 (16px에서는 구름 디테일 생략 가능) |

이보다 작아지면 구름·수평선 디테일이 뭉개져 명료함(Clarity) 가치를 해칩니다. 더 작게 표기해야 하는 맥락이면 축약 대신 심볼만 사용을 검토합니다.

## 3. 여백 (Clear Space)

로고 주위에는 다른 텍스트·아이콘·모서리가 침범할 수 없는 여백을 둡니다.

- **기준 단위 X** = 심볼 원(태양)의 지름.
- 로고의 상하좌우 모든 방향에 **최소 1X**의 여백을 확보합니다.
- 앱 내 배치(툴바, 카드 헤더 등)에서는 여백을 `dimension.space.4`(16px) 이상으로 대체 적용해도 됩니다. 단, 계산된 1X보다 작아지지 않아야 합니다.

## 4. 배경별 사용

| 배경 | 사용 파일 | 규칙 |
| :-- | :-- | :-- |
| 라이트 배경 (`color.bg.base`, `color.bg.subtle`) | `logo.svg` | 기본 조합. 뉴트럴 요소는 `color.fg.base`(짙은 뉴트럴)로 표시되어 대비를 확보. |
| 다크 배경 (`color.bg.inverse`, 다크 테마 `color.bg.base`) | `logo-dark.svg` | 뉴트럴 요소를 `color.fg.onInverse`(밝은 뉴트럴)로 반전. 심볼의 원은 동일하게 `color.brand.default` 유지. |
| 브랜드색 위 (`color.brand.default` 배경 등 브랜드 블루 위) | `logo-dark.svg` | 브랜드색 배경 위에서는 원(태양) 대신 워드마크·수평선의 흰 버전이 주 식별 요소가 되도록 다크 버전을 사용. 원의 블루가 배경과 섞여 사라지지 않는지 반드시 육안 확인. |
| 사진/그라데이션 위 | 상황에 맞는 버전 선택 후, 로고 뒤에 반투명 스크림(오버레이)을 추가해 대비를 4.5:1 이상 확보 | 스크림 없이 저대비 사진 위에 직접 배치 금지. |

## 5. 금지 사례

| 금지 항목 | 설명 |
| :-- | :-- |
| 비율 왜곡 | 가로/세로 비율을 다르게 늘리거나 줄이지 않는다. |
| 색상 변경 | 원(태양)의 브랜드 블루를 다른 색으로 바꾸지 않는다. 단색(모노톤) 필요 시에도 명도만 조정하고 색상은 유지. |
| 그림자·입체 효과 | 드롭섀도, 엠보스, 그라데이션 오버레이 등 장식 효과를 추가하지 않는다 — 잔잔함(Calm) 가치와 상충. |
| 회전·기울임 | 로고를 회전하거나 기울여 배치하지 않는다. |
| 저대비 배경 | 배경과 로고 요소의 대비가 3:1 미만인 곳에 직접 배치하지 않는다(§4의 스크림 규칙 적용). |
| 재구성 | 심볼과 워드마크의 간격·정렬을 임의로 바꾸거나 워드마크만 다른 폰트로 다시 그리지 않는다. |
| 텍스트 안에 삽입 | 로고를 본문 문장 안에 인라인 아이콘처럼 섞어 쓰지 않는다. |
| 배경 박스 추가 | 로고 주위에 임의의 색 배경 도형(뱃지 등)을 추가하지 않는다. 필요하면 여백(§3) 안에서 해결한다. |
