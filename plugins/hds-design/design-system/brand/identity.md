# 브랜드 아이덴티티

> 이 문서는 사람과 AI가 함께 읽는 규범입니다. 마케팅 카피, 온보딩 문구, 프로모 자산을 만들 때 반드시 이 정의를 근거로 삼습니다.

## 0. 한 줄 정리

| 항목 | 내용 |
| :-- | :-- |
| 회사 | (주)하늘 (Haneul Inc.) |
| 제품 | 하늘 — 날씨 기반 일상 플래너 앱 |
| 슬로건 | 일상을 하늘에 맞추다 |
| 핵심 기능 | 오늘 브리핑(날씨+일정 요약) · 주간 플랜 · 스마트 알림 |

## 1. 미션 · 비전 · 브랜드 가치

세 개념은 층위가 다릅니다. **미션은 "왜 존재하는가"**, **비전은 "무엇이 되려 하는가"**, **브랜드 가치는 "어떻게 행동하는가"**입니다. 카피를 쓸 때 이 층위를 섞지 않습니다.

| 구분 | 정의 |
| :-- | :-- |
| 미션 | 날씨와 일정을 하나의 흐름으로 엮어, 사람들이 하루를 미리 예측하고 마음 편히 준비하게 돕는다. |
| 비전 | 날씨를 "확인하는" 앱이 아니라, 하루를 미리 알려주는 조용한 동반자가 된다. |

### 브랜드 가치 3종

| 가치 | 정의 | 제품에 반영되는 방식 |
| :-- | :-- | :-- |
| 명료함 (Clarity) | 필요한 정보만 먼저 보여주고, 판단은 사용자가 하게 한다. | 오늘 브리핑은 날씨·일정 요약을 한 화면에, 위계 3단계 이내로 구성(`guidelines/typography.md` 참조). 불필요한 수치·전문용어 노출 금지. |
| 잔잔함 (Calm) | 알림도 정보도 조용히, 필요한 순간에만 전한다. | 모션은 `duration.base` 중심의 절제된 진입/퇴장만 사용(`guidelines/motion.md`). 긴급하지 않은 알림에 강조 애니메이션·사운드를 남용하지 않는다. |
| 신뢰 (Trust) | 예보가 틀릴 수 있음을 숨기지 않고, 사용자가 대비할 수 있게 정직하게 전달한다. | 불확실성이 있는 예보는 단정형 대신 완곡한 어미 사용(`voice-tone.md` 참조). 오류·지연 상황도 명확히 안내한다. |

## 2. 브랜드 퍼스낼리티

하늘은 사람이라면 이런 모습입니다 — 아침 일찍 창밖을 보고 오늘 우산이 필요한지 조용히 알려주는, 말이 많지 않지만 정확한 친구.

| 이런 성격입니다 | 이런 성격은 아닙니다 |
| :-- | :-- |
| 차분하고 정확함 | 호들갑스럽거나 과장됨 |
| 필요한 말만 간결하게 | 수다스럽거나 장황함 |
| 존댓말로 예의를 지킴 | 반말·유행어로 친근함을 가장함 |
| 데이터를 근거로 정직하게 안내 | 불확실한 것을 단정적으로 말함 |
| 배경처럼 조용히 곁에 있음 | 시선을 끌기 위해 소란스러움 |

## 3. 네이밍 규칙

제품명·기능명은 브랜드 가치(명료함·잔잔함·신뢰)를 언어로도 지킵니다.

| 규칙 | 설명 |
| :-- | :-- |
| 기본 표기 | 한국어 서비스명은 "하늘"(한글) 우선. 영문 병기가 필요하면 "Haneul"(대문자 H, 로마자 표기법 준수). |
| 음절 수 | 기능명은 2~4음절 명사형을 우선한다. 예: 브리핑, 주간 플랜, 스마트 알림. |
| 은유 사용 | 날씨·하늘 은유(맑음, 흐림, 갬, 스밈 등)는 허용하되 문자 그대로의 기상 용어와 혼동되지 않게 한다. |
| 과장 금지 | "완벽한", "최고의", "무조건" 등 단정·과장 수식어는 기능명에 쓰지 않는다. |
| 영문 혼용 금지 | 기능명 내부에 영문 약어(AI, Pro 등)를 임의로 섞지 않는다. 필요 시 별도 검토를 거친다. |
