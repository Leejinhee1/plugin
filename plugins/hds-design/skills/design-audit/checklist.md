# 비주얼 감사 체크리스트

각 항목은 "무엇을 보고 어떻게 판정하는지"를 담습니다. 근거 문서를 대조해 pass/fail 또는 관찰 메모를 남기세요.

## 1. 시각 위계
- [ ] 화면에서 가장 먼저 눈이 가는 요소가 사용자의 핵심 과업과 일치하는가 — 1단계 첫인상과 대조해 판정. (근거: `guidelines/principles.md` 원칙 1)
- [ ] 제목/본문/보조 텍스트 위계가 3단계 이내로 명확히 구분되는가. (근거: `guidelines/typography.md`)
- [ ] 화면당 primary 액션이 정확히 1개인가 — 2개 이상이면 위계 붕괴로 판정. (근거: `guidelines/color.md` "브랜드 색은 강조에만")
- [ ] 스크롤 없이 핵심 정보가 첫 화면(first fold)에 들어오는가.
- [ ] 정보 밀도가 화면 목적에 비해 과하거나(빽빽함) 부족하지(휑함) 않은가.
- [ ] 반복 요소(리스트/카드)가 시각적으로 동일한 무게로 처리돼 위계를 흐리지 않는가.

## 2. 타이포 (근거: `guidelines/typography.md`)
- [ ] 폰트 패밀리가 `fontFamily.sans` 하나로 고정돼 있는가 — 임의 폰트 삽입 여부 확인.
- [ ] 텍스트 크기가 정의된 스케일(xs·sm·md·lg·xl·2xl·3xl)에만 해당하는가 — 임의 px 값이 보이면 지적.
- [ ] 굵기 사용이 4단계(regular/medium/semibold/bold) 내로 제한되는가.
- [ ] 본문 줄 길이가 45~75자 범위인가 — 컨테이너 폭이 지나치게 넓거나 좁지 않은지 확인.
- [ ] 라벨/보조 설명에 맞는 role(`typography.label`/`typography.caption`)이 쓰였는가 — 본문 스타일 재사용 여부 확인.
- [ ] role별 지정 줄간격(예: body 1.5)이 실제로 적용됐는가.

## 3. 색·대비 (근거: `guidelines/color.md`)
- [ ] 본문 텍스트/배경 대비가 4.5:1 이상인가 — 미달 의심 시 수치 확인 후 blocker.
- [ ] 큰 텍스트(24px 이상, 또는 19px bold 이상)의 대비가 3:1 이상인가.
- [ ] 인터랙티브 컴포넌트 경계·아이콘의 대비가 3:1 이상인가.
- [ ] feedback 색(success/warning/danger)이 의미대로만 쓰였는가 — 장식 목적 사용 여부 확인.
- [ ] 색만으로 정보를 구분하지 않는가 — 아이콘/텍스트 병행 여부.
- [ ] 다크 테마로 전환해도 대비가 유지되는가(가능하면 라이트/다크 둘 다 확보).

## 4. 간격·정렬 (근거: `tokens/semantic.tokens.json` space, `guidelines/principles.md` 원칙 2)
- [ ] 요소 간 여백이 space 토큰 스케일(inset/stack 등) 값에 맞는가 — 13px·22px 같은 임의 px 흔적은 하드코딩 의심.
- [ ] 좌우 정렬 기준선이 화면 전체에서 일관되는가(컨테이너 폭·그리드 통일).
- [ ] 카드/리스트 내부 여백이 해당 컴포넌트 spec의 값과 일치하는가.
- [ ] 텍스트와 인접 아이콘/버튼의 수직 정렬(baseline/center)이 흐트러지지 않았는가.
- [ ] 반복 그룹(리스트 항목 등) 사이 간격이 그룹 내부 간격보다 크게 구분되는가(stack 리듬).

## 5. 인터랙션 상태 (근거: `guidelines/principles.md` 원칙 3, 해당 컴포넌트 `spec.md`)
- [ ] 클릭 가능 요소에 hover 상태가 정의돼 있는가.
- [ ] 키보드 포커스 시 `focus-visible` 링이 보이는가 — `color.focus.ring` 토큰 사용 여부.
- [ ] disabled 상태가 시각적으로(대비 낮춤 등) 명확히 구분되는가.
- [ ] 비동기 로딩 상태(스피너/스켈레톤)가 있는가 — 없는 화면이면 지적.
- [ ] 에러/빈 상태 문구가 `brand/voice-tone.md` 규칙(해요체, 과장·이모지 없음)을 따르는가.
- [ ] 폼 검증 에러가 색만이 아니라 텍스트/아이콘으로도 표시되는가.

## 6. 반응형·모션 (근거: `guidelines/motion.md`)
- [ ] 모바일 폭에서 레이아웃이 깨지지 않는가(줄바꿈·잘림·겹침 확인).
- [ ] 애니메이션 duration이 `fast`/`base`/`slow` 중 하나로 설명 가능한가 — 임의 값 의심 시 지적.
- [ ] 진입 모션은 emphasized, 종료 모션은 standard 이징 원칙과 맞는가.
- [ ] `prefers-reduced-motion: reduce` 환경에서 애니메이션이 최소화되는가(코드/설명으로 확인).
- [ ] 장식 목적의 애니메이션(의미 없는 반복 모션)이 없는가.
