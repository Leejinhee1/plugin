# 모션 · 영상 가이드

> 제품 UI의 모션 언어(`guidelines/motion.md`)를 영상·프로모 자산까지 확장합니다. 영상만 다른 속도감으로 만들지 않습니다 — 사용자가 앱과 영상을 같은 브랜드로 인지하려면 듀레이션·이징이 같은 언어여야 합니다.

## 1. 토큰 → 영상 타임라인 매핑 규칙

`tokens/core.tokens.json`의 `duration` · `cubicBezier` 토큰을 영상 편집 타임라인(프레임 단위)으로 환산할 때는 아래 표를 따릅니다. ms 값을 임의로 반올림하지 않고 이 표만 참조합니다.

| 토큰 | 값 | 24fps 환산 | 30fps 환산 | 용도 |
| :-- | :-- | :-- | :-- | :-- |
| `duration.fast` | 120ms | 3프레임 | 4프레임 | 아이콘·작은 UI 컷의 등장/전환 |
| `duration.base` | 200ms | 5프레임 | 6프레임 | 기본 컷 전환, 텍스트 등장 (가장 많이 쓰임) |
| `duration.slow` | 320ms | 8프레임 | 10프레임 | 장면 전환, 로고 모션 |
| `cubicBezier.standard` | `[0.2, 0, 0, 1]` | — | — | 진입 마무리·퇴장 전 구간에 사용. 영상 편집 툴의 easing 곡선에 동일 좌표로 입력 |
| `cubicBezier.emphasized` | `[0.3, 0, 0.1, 1]` | — | — | 강조 진입(로고 등장, 핵심 문구 강조)에 사용 |

**규칙**
- 컷 전환·모션 그래픽 듀레이션은 항상 `fast` / `base` / `slow` 중 하나에서 고른다. 임의의 애매한 길이(예: 250ms)를 쓰지 않는다.
- 진입 모션은 `emphasized`, 퇴장·소멸 모션은 `standard` + 가능하면 `fast`~`base` 사이의 짧은 값을 쓴다(`guidelines/motion.md`와 동일 원칙).
- `prefers-reduced-motion` 상당의 배려로, 프로모 영상에도 과도한 카메라 흔들림·급격한 확대/축소를 쓰지 않는다.

## 2. 인트로 / 전환 / 로고 모션 사양

| 장면 | 목적 | 듀레이션 토큰 | 이징 | 설명 |
| :-- | :-- | :-- | :-- | :-- |
| 오프닝 페이드인 | 브랜드 진입, 시선 정리 | `duration.slow` | `standard` | 어두운/빈 화면에서 첫 비주얼로 서서히 전환. |
| 워드마크 등장("하나" → "머니") | 브랜드 각인 | `duration.base` | `emphasized` | 하나그린 "하나"가 먼저 페이드+짧은 상승으로 등장하고, "머니"가 이어서 등장. 한 번에 하나의 움직임만. |
| 그린 그라데이션 배경 전환 | 브랜드 톤 연결 | `duration.slow` | `standard` | `brand.subtle` → `brand.default` 단일 계열 그라데이션만 사용(`visual-style.md` §3). |
| 장면 간 컷 전환 | 정보 단위 구분 | `duration.base` | `standard` | 크로스페이드 또는 좌우 슬라이드. 화려한 트랜지션(회전, 큐브 등) 금지. |
| 자막/카피 등장 | 정보 전달 | `duration.base` | `standard` | 자막은 최소 1.5초 이상 고정 노출 후 퇴장(이는 듀레이션 토큰과 별개의 가독성 규칙). |
| 엔딩(로고 고정 + 슬로건) | 마무리, 잔상 | `duration.slow` | `standard` | 마지막 프레임은 로고+슬로건 정지 화면으로 최소 1초 이상 유지. |

## 3. 사운드 톤 가이드

배경음·효과음도 "절제(Restraint)"와 "신뢰(Trust)" 가치를 따릅니다. 음악은 미니멀하고 잔향이 적은 어쿠스틱/앰비언트 계열을 기본으로 하고, 급격한 드롭이나 EDM식 긴장감 조성 편곡은 피합니다. 효과음(SFX)은 로고 등장, 알림 화면 전환 등 핵심 순간에만 짧고 절제된 소리(예: 낮은 차임 1회)를 넣고, 컷마다 효과음을 넣어 소란스럽게 만들지 않습니다. 내레이션이 있다면 `voice-tone.md`의 원칙과 동일하게 차분한 존댓말, 빠르지 않은 속도로 녹음합니다.
