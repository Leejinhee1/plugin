# 비주얼 스타일

> 사진·일러스트·마케팅 그래픽을 만들거나 검수할 때 근거로 삼는 규범입니다. 제품 UI 토큰(`tokens/`)과 같은 언어를 씁니다 — 브랜드 자산만 따로 노는 것을 금지합니다.

## 1. 키 비주얼 방향

브랜드 가치 3종(명료함·잔잔함·신뢰)을 시각으로 옮기면 다음 세 단어가 됩니다.

| 방향 | 의미 | 구현 |
| :-- | :-- | :-- |
| 하늘 | 날씨라는 제품 도메인을 직접적으로, 과장 없이 드러낸다. | 실제 하늘 사진/일러스트, 맑음~흐림의 자연스러운 스펙트럼. 합성감이 강한 초현실적 하늘 지양. |
| 빛 | 정보가 선명하게 보이도록 밝고 여유 있는 톤을 쓴다. | 저채도·중고명도 위주. 인물·UI 스크린샷이 배경에 묻히지 않게 대비를 확보. |
| 여백 | 화면과 이미지 모두 숨 쉴 공간을 남긴다. | 피사체를 화면의 40~60%로 제한하고 나머지는 여백. 텍스트가 들어갈 영역을 미리 비워둔다. |

## 2. 사진/일러스트 스타일 규칙

| 항목 | 규칙 |
| :-- | :-- |
| 피사체 | 실제 하늘·창밖 풍경·일상 속 순간(우산, 창가, 걷는 사람 등)을 우선한다. 스톡처럼 보이는 과장된 연출(억지 웃음, 인위적 포즈)은 피한다. |
| 색감 | 채도를 낮추고 자연광 톤을 유지한다. 인공적인 원색 보정, 강한 비네팅을 쓰지 않는다. |
| 인물 | 등장할 경우 표정은 차분하게. 브랜드 퍼스낼리티(`identity.md` §2)와 마찬가지로 소란스럽지 않게. |
| 일러스트 | 심볼(`logo.md`)과 동일한 기하학적 어휘(원·수평선·완만한 곡선)를 확장해서 쓴다. 복잡한 디테일, 캐릭터화된 마스코트는 만들지 않는다. |
| 아이콘 | 제품 아이콘은 `components/`의 기존 아이콘 세트를 따른다. 브랜드 자산에서 새 아이콘 스타일을 임의로 만들지 않는다. |

## 3. 그래픽 모티프 사용 규칙

로고 심볼에서 파생된 세 가지 모티프를 브랜드 그래픽 전반에서 재사용합니다. 모티프는 절제해서 쓰고, 한 화면/장면에 최대 2개까지만 조합합니다.

| 모티프 | 의미 | 사용 규칙 |
| :-- | :-- | :-- |
| 수평선 | 명료함, 하루의 경계(오늘/내일) | 화면 하단 1/3 지점 부근에 얇은 선 또는 색 경계로 배치. 여러 개를 겹쳐 쓰지 않는다. |
| 구름 | 잔잔함, 날씨의 변화 | 작은 점/원의 군집으로 단순화해서 쓴다. 사실적인 뭉게구름 일러스트는 피한다. |
| 그라데이션 | 신뢰, 하늘의 시간대 변화(새벽~노을) | `color.brand.subtle` → `color.brand.default` 방향의 단일 계열 그라데이션만 허용. 무지개색·다색 그라데이션 금지. 텍스트가 올라가는 영역에는 그라데이션 대비를 낮춰 가독성을 확보한다. |

## 4. 색 사용 (semantic 토큰 기준)

브랜드 자산의 색은 항상 semantic 토큰 이름으로 지정합니다. core 값을 직접 참조하지 않습니다(예외: `assets/*.svg` 원본 파일은 렌더링을 위해 hex를 쓰되 주석으로 토큰 출처를 명기).

| 용도 | 토큰 |
| :-- | :-- |
| 주 강조(심볼, 핵심 CTA 배경) | `color.brand.default` |
| 강조 배경(그라데이션 옅은 쪽, 카드 하이라이트) | `color.brand.subtle` |
| 호버/눌림 상태 그래픽 | `color.brand.hover` / `color.brand.active` |
| 기본 배경 | `color.bg.base` / `color.bg.subtle` |
| 반전 배경(다크, 브랜드색 위 텍스트) | `color.bg.inverse`, `color.fg.onInverse`, `color.fg.onBrand` |
| 텍스트 | `color.fg.base`(주요), `color.fg.muted`(보조) |
| 경계선 | `color.border.base` |

브랜드 색은 화면당 하나의 주인공에만 집중합니다(`guidelines/color.md`의 "브랜드 색은 강조에만" 원칙과 동일). 마케팅 자산이라고 해서 브랜드 블루를 배경 전체에 남용하지 않습니다.
