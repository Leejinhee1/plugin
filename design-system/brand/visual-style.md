# 비주얼 스타일

> 사진·일러스트·마케팅 그래픽을 만들거나 검수할 때 근거로 삼는 규범입니다. 제품 UI 토큰(`tokens/`)과 같은 언어를 씁니다 — 브랜드 자산만 따로 노는 것을 금지합니다. 디자인 언어는 HES(Hana Experience System)와 동기화합니다.

## 1. 키 비주얼 방향

브랜드 가치 3종(명확함·신뢰·절제)을 시각으로 옮기면 다음 세 단어가 됩니다.

| 방향 | 의미 | 구현 |
| :-- | :-- | :-- |
| 그린 | 하나그린(`color.brand.default`)이 곧 브랜드 식별자다. | 주 강조·CTA·심볼에만 하나그린. 배경 전체를 그린으로 덮지 않는다. 틸 램프(`color.teal.*`)는 상태·그라데이션 보조로만. |
| 빛 | 금융 정보가 선명하게 보이도록 밝고 정돈된 톤을 쓴다. | 흰 배경(`bg.base`) + 쿨 그레이(`grayScale`) 위주. 저채도·고명도. 숫자·그래프가 배경에 묻히지 않게 대비 확보. |
| 여백 | 신뢰는 정돈에서 나온다 — 화면과 이미지 모두 숨 쉴 공간을 남긴다. | 피사체를 화면의 40~60%로 제한하고 나머지는 여백. 텍스트가 들어갈 영역을 미리 비워둔다. |

## 2. 사진/일러스트 스타일 규칙

| 항목 | 규칙 |
| :-- | :-- |
| 피사체 | 결제·적립이 일어나는 일상 장면(카페 결제, 장보기, 여행)을 우선한다. 스톡처럼 보이는 과장된 연출(억지 웃음, 돈다발 이미지)은 피한다. |
| 색감 | 채도를 낮추고 자연광 톤을 유지한다. 그린 계열 소품/배경으로 브랜드 톤을 은은하게 연결하되 인공적인 원색 보정은 쓰지 않는다. |
| 인물 | 등장할 경우 표정은 차분하게. 브랜드 퍼스낼리티(`identity.md` §2)와 마찬가지로 소란스럽지 않게. |
| 일러스트 | 단순한 기하 도형(원·라운드 사각·완만한 곡선)과 하나그린+틸 램프 조합. 복잡한 디테일, 캐릭터화된 마스코트는 만들지 않는다. |
| 아이콘 | 제품 아이콘은 `components/`의 기존 아이콘 세트를 따른다. 브랜드 자산에서 새 아이콘 스타일을 임의로 만들지 않는다. |
| 금액 표기 | 비주얼 안의 금액·수치는 실존 상품 조건으로 오인되지 않게 예시임을 명시하거나 일반화된 수치를 쓴다. |

## 3. 그래픽 모티프 사용 규칙

브랜드 그래픽 전반에서 재사용하는 모티프입니다. 모티프는 절제해서 쓰고, 한 화면/장면에 최대 2개까지만 조합합니다.

| 모티프 | 의미 | 사용 규칙 |
| :-- | :-- | :-- |
| 라운드 사각 | 카드·머니의 은유, HES의 기본 형태 언어 | `dimension.radius.*` 스케일(4~24px)만 사용. 임의의 radius 값 금지. |
| 그린 그라데이션 | 하나그린의 깊이, 신뢰 | `color.brand.subtle`(teal.70) → `color.brand.default` 방향의 단일 계열 그라데이션만 허용. 무지개색·다색 그라데이션 금지. 텍스트가 올라가는 영역에는 그라데이션 대비를 낮춰 가독성을 확보한다. |
| 포인트 컬러 칩 | 적립·혜택의 순간 강조 | `color.hana.pointgreen`·디지털 팔레트(`color.hana.digital*`)는 프로모·일러스트 포인트로만 소량 사용. UI 본문·상태색으로 쓰지 않는다. |

## 4. 색 사용 (semantic 토큰 기준)

브랜드 자산의 색은 항상 semantic 토큰 이름으로 지정합니다. core 값을 직접 참조하지 않습니다(예외: `assets/*.svg` 원본 파일은 렌더링을 위해 hex를 쓰되 주석으로 토큰 출처를 명기).

| 용도 | 토큰 |
| :-- | :-- |
| 주 강조(심볼, 핵심 CTA 배경) | `color.brand.default` (하나그린 #009178) |
| 강조 배경(그라데이션 옅은 쪽, 카드 하이라이트) | `color.brand.subtle` |
| 호버/눌림 상태 그래픽 | `color.brand.hover` / `color.brand.active` |
| 기본 배경 | `color.bg.base` / `color.bg.subtle` |
| 반전 배경(다크, 브랜드색 위 텍스트) | `color.bg.inverse`, `color.fg.onInverse`, `color.fg.onBrand` |
| 텍스트 | `color.fg.base`(주요), `color.fg.muted`(보조) |
| 경계선 | `color.border.base` |

브랜드 색은 화면당 하나의 주인공에만 집중합니다(`guidelines/color.md`의 "브랜드 색은 강조에만" 원칙과 동일). 마케팅 자산이라고 해서 하나그린을 배경 전체에 남용하지 않습니다.
