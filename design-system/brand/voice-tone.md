# 보이스 & 톤

> 이 문서는 UI 문구, 알림, 마케팅 카피를 쓰는 사람과 AI를 위한 규범입니다. `identity.md`의 브랜드 가치(명확함·신뢰·절제)를 문장 단위로 구현합니다.

## 1. 보이스 원칙 (상황이 바뀌어도 변하지 않는 것)

1. **차분한 존댓말**: 항상 해요체를 기본으로 한다. 반말·명령형 어미를 쓰지 않는다.
2. **간결함**: 한 문장에 하나의 정보만 담는다. 수식어를 줄이고 동사를 직접적으로 쓴다.
3. **과장·이모지 남용 금지**: 느낌표 연속 사용, 이모지 장식, "대박/최고" 류의 감탄 표현을 쓰지 않는다. 혜택은 조건과 함께, 사실만 말한다(금융광고 표현 심의 관점에서도 필수).
4. **정직함**: 오류·지연·수수료는 얼버무리지 않고 있는 그대로, 다음 행동과 함께 전달한다.
5. **사람을 주어로**: "시스템이 ~합니다"보다 "~해드릴게요/확인해 주세요"처럼 사용자 행동 중심으로 쓴다.

톤은 상황마다 미세하게 조정되지만, 보이스(위 5원칙)는 항상 고정입니다.

## 2. 상황별 톤

| 상황 | 톤 | 좋은 예 | 나쁜 예 |
| :-- | :-- | :-- | :-- |
| 온보딩 | 차분하게 환영, 부담 없는 안내 | "안녕하세요. 지금부터 하나머니가 결제와 적립을 함께 챙겨드릴게요." | "환영합니다!! 지금 바로 충전하고 인생 혜택 챙겨가세요 🎉" |
| 오류 | 담담하게 사실 전달 + 다음 행동 제시 | "결제 내역을 불러오지 못했어요. 잠시 후 다시 시도해 주세요." | "오류 발생! 큰일났어요 ㅠㅠ 다시 눌러보세요!" |
| 빈 상태 | 부담 주지 않는 안내, 다음 행동 제안 | "아직 적립 내역이 없어요. 첫 결제부터 자동으로 쌓아드릴게요." | "텅 비어있네요! 얼른 채워보세요 🔥" |
| 알림(결제/적립) | 필요한 정보만, 조용한 어조, 금액은 정확하게 | "스타벅스에서 5,600원 결제되고 56원이 적립됐어요." | "긴급! 포인트가 쌓였어요, 지금 당장 확인 안 하면 손해!!!" |
| 혜택/마케팅 | 담백한 제안, 조건 명시 | "이번 달 편의점 결제분은 2% 적립돼요. (월 최대 5,000원)" | "무조건 퍼주는 미친 적립! 하나머니 지금 다운로드하지 않으면 후회합니다!" |
| 보안/이상거래 | 침착하게 사실 + 즉시 할 일 | "평소와 다른 기기에서 로그인이 확인됐어요. 본인이 아니라면 비밀번호를 변경해 주세요." | "⚠️경고⚠️ 해킹 의심!!! 계정이 위험합니다!!" |

## 3. UI 문구 스타일 규칙

| 항목 | 규칙 | 예시 |
| :-- | :-- | :-- |
| 존댓말 | 해요체 기본. 버튼·라벨처럼 짧은 UI 요소는 명사형도 허용(예: "충전", "다시 시도"). | "5,000원을 충전했어요." / 버튼: "충전하기" |
| 문장부호 | 본문 문장은 마침표를 쓴다. 버튼·라벨·탭 이름 등 짧은 UI 텍스트는 마침표를 생략한다. 느낌표는 원칙적으로 쓰지 않는다(보안 경고 등 예외는 최대 1개). | 본문: "적립이 완료됐어요." / 버튼: "확인" |
| 금액 표기 | 아라비아 숫자 + 천 단위 콤마 + "원"/"머니"를 붙여 쓴다. 반올림·축약(5.6천원)을 하지 않는다. | "12,500원", "3,000머니" |
| 날짜 표기 | "M월 D일 (요일)" 형식을 기본으로 한다. 연도는 다른 해를 표기할 때만 추가. | "7월 20일 (월)" |
| 시간 표기 | "오전/오후 H:MM" 12시간제를 기본으로 한다. 24시간제는 거래 내역 상세 등 명시적 맥락에서만 노출. | "오후 3:00" |
| 상대 시간 | 하루 이내는 상대 표현, 그 이후는 절대 날짜. | "1시간 전", "어제", "7월 12일" |
| 높임 대상 | 사용자에게는 존댓말, 서비스 자신은 중립적으로("하나머니가 알려드릴게요"). | "하나머니가 이번 달 적립을 정리했어요." |
