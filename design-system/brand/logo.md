# 로고

> 원본 벡터: `brand/assets/logo.svg`(라이트 배경용), `brand/assets/logo-dark.svg`(다크 배경용). 이 문서는 두 파일의 사용 규칙입니다.
>
> ⚠️ **하나금융그룹 공식 심볼(CI)은 이 저장소에서 관리하지 않습니다.** 그룹 CI 심볼·시그니처는 그룹 브랜드 가이드와 CI팀 제공 원본만 사용해야 하며, 여기서 재작도(트레이싱)하지 않습니다. 이 저장소의 SVG는 **하나머니 워드마크 플레이스홀더**로, 공식 시그니처 에셋을 받으면 교체합니다.

## 1. 구성 요소

| 요소 | 설명 |
| :-- | :-- |
| 워드마크 | "하나머니" 한글 로고타입. `fontFamily.sans`(Spoqa Han Sans Neo 우선) 기반 볼드. |
| 색 | 워드마크의 "하나"는 `color.brand.default`(하나그린) 고정, "머니"는 뉴트럴 톤(배경에 따라 전환, §4 참조). |
| 그룹 시그니처 | 하나 CI 심볼과의 조합(lockup)은 그룹 브랜드 가이드 규정을 따른다 — 임의 조합 금지. |

## 2. 최소 크기

| 매체 | 최소 크기(워드마크 기준) |
| :-- | :-- |
| 디지털 UI | 높이 16px 이상 |
| 인쇄물 | 높이 8mm 이상 |
| 파비콘 / 앱 아이콘 | 워드마크 축소 사용 금지 — 전용 앱 아이콘 에셋(별도 관리)만 사용 |

이보다 작아지면 한글 획이 뭉개져 명확함(Clarity) 가치를 해칩니다.

## 3. 여백 (Clear Space)

로고 주위에는 다른 텍스트·아이콘·모서리가 침범할 수 없는 여백을 둡니다.

- **기준 단위 X** = 워드마크의 글자 높이.
- 로고의 상하좌우 모든 방향에 **최소 0.5X**의 여백을 확보합니다.
- 앱 내 배치(툴바, 카드 헤더 등)에서는 여백을 `dimension.space.80`(16px) 이상으로 대체 적용해도 됩니다. 단, 계산된 0.5X보다 작아지지 않아야 합니다.

## 4. 배경별 사용

| 배경 | 사용 파일 | 규칙 |
| :-- | :-- | :-- |
| 라이트 배경 (`color.bg.base`, `color.bg.subtle`) | `logo.svg` | 기본 조합. 뉴트럴 요소는 `color.fg.base`로 표시되어 대비를 확보. |
| 다크 배경 (`color.bg.inverse`, 다크 테마 `color.bg.base`) | `logo-dark.svg` | 뉴트럴 요소를 `color.fg.onInverse`(흰색)로 반전. "하나"의 그린은 다크에서도 유지하되 대비 3:1 미만이면 전체 흰색 버전을 쓴다. |
| 브랜드색 위 (`color.brand.default` 배경 등 하나그린 위) | `logo-dark.svg`의 전체 흰색 변형 | 그린 위 그린이 되지 않도록 워드마크 전체를 `color.fg.onBrand`(흰색)로. |
| 사진/그라데이션 위 | 상황에 맞는 버전 선택 후, 로고 뒤에 반투명 스크림(오버레이)을 추가해 대비를 4.5:1 이상 확보 | 스크림 없이 저대비 사진 위에 직접 배치 금지. |

## 5. 금지 사례

| 금지 항목 | 설명 |
| :-- | :-- |
| 비율 왜곡 | 가로/세로 비율을 다르게 늘리거나 줄이지 않는다. |
| 색상 변경 | "하나"의 하나그린을 다른 색으로 바꾸지 않는다. 단색(모노톤) 필요 시에도 명도만 조정하고 색상은 유지. |
| 그림자·입체 효과 | 드롭섀도, 엠보스, 그라데이션 오버레이 등 장식 효과를 추가하지 않는다 — 절제(Restraint) 가치와 상충. |
| 회전·기울임 | 로고를 회전하거나 기울여 배치하지 않는다. |
| 저대비 배경 | 배경과 로고 요소의 대비가 3:1 미만인 곳에 직접 배치하지 않는다(§4의 스크림 규칙 적용). |
| 재구성 | 워드마크를 다른 폰트로 다시 그리거나 글자 간격을 임의로 바꾸지 않는다. |
| CI 임의 사용 | 그룹 CI 심볼을 CI팀 원본 없이 재작도·변형·조합하지 않는다. |
| 텍스트 안에 삽입 | 로고를 본문 문장 안에 인라인 아이콘처럼 섞어 쓰지 않는다. |
| 배경 박스 추가 | 로고 주위에 임의의 색 배경 도형(뱃지 등)을 추가하지 않는다. 필요하면 여백(§3) 안에서 해결한다. |
